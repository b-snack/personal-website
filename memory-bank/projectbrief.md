# Project Brief

## Project Overview

**Sebastian Wu Personal Portfolio Website** - A modern, interactive personal portfolio website showcasing Sebastian Wu's skills, interests, and projects. The website features a bento-grid layout with real-time integrations (weather, music, time), interactive components, and a full-stack architecture with React frontend and Node.js/Express backend.

## Core Requirements

1. **Personal Branding**: Showcase Sebastian's identity as a Grade 11 IB student, developer, and speedcuber
2. **Real-time Features**: Display current time, weather in Ottawa, and Last.fm music playback
3. **Interactive Components**:
   - Time travel slider for exploring past snapshots
   - Photography gallery
   - Guestbook with like system
   - Speedcubing statistics and timer
   - Konami code easter egg (shatter effect)
4. **Responsive Design**: Modern bento-grid layout that works across devices
5. **Full-Stack Architecture**: Frontend (React) + Backend (Node.js/Express + MongoDB)

## Key Goals

- Create an engaging, visually appealing portfolio that reflects personality
- Demonstrate technical skills through interactive features
- Provide visitors with multiple ways to engage (guestbook, exploring content)
- Maintain clean, maintainable code with proper separation of concerns

## Success Metrics

- Website loads quickly and works reliably
- All interactive features function correctly
- Visitors can easily navigate and engage with content
- Codebase is well-documented and extensible

## Project Scope

**Included**:

- Frontend React application with bento-grid layout
- Backend API for guestbook, snapshots, and like system
- MongoDB database for persistent storage
- Integration with external APIs (Open-Meteo, Last.fm)
- Interactive components (TimeTravelSlider, Photography, Guestbook, Cubing, KonamiShatter)

**Out of Scope**:

- User authentication system
- Admin dashboard
- E-commerce functionality
- Mobile app version

## Timeline & Status

- **Current Status**: Active development, functional with core features implemented
- **Last Major Update**: Implementation of like system for guestbook
- **Next Phase**: Potential enhancements to photography gallery, resume integration, additional interactive features
