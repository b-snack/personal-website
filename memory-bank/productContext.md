# Product Context

## Why This Project Exists

This personal portfolio website serves as a digital representation of Sebastian Wu's identity, skills, and interests. It addresses the need for:

1. **Professional Presence**: A centralized platform for potential employers, university admissions, and peers to learn about Sebastian
2. **Skill Demonstration**: Showcasing technical abilities through interactive features and clean code
3. **Personal Expression**: Reflecting personality through design choices, content, and interactive elements
4. **Learning Platform**: A practical project for experimenting with full-stack development, API integrations, and modern web technologies

## Problems It Solves

1. **Portfolio Fragmentation**: Consolidates multiple aspects (coding projects, photography, speedcubing) into one cohesive experience
2. **Static Portfolios**: Replaces traditional static portfolios with dynamic, engaging content
3. **Visitor Engagement**: Provides interactive ways for visitors to connect (guestbook, exploring content)
4. **Real-time Information**: Displays current context (time, weather, music) to create a living, breathing website

## How It Should Work

### User Experience Goals

1. **First-Time Visitors**:

   - Immediately understand who Sebastian is and what he does
   - Discover interactive elements through visual cues
   - Easily navigate between different sections
   - Leave a message in the guestbook

2. **Returning Visitors**:

   - Notice updated content (new photos, guestbook messages)
   - Explore deeper features (time travel, cubing statistics)
   - Enjoy consistent, polished experience

3. **Technical Evaluators**:
   - Appreciate clean code architecture
   - Notice performance optimizations
   - Understand technical decisions through code quality

### Key User Flows

1. **Homepage Exploration**:

   - Land on bento-grid homepage
   - Scan hero section for quick introduction
   - Interact with real-time widgets (time, weather, music)
   - Click on photography/navigation cards for more content

2. **Guestbook Interaction**:

   - Open guestbook modal
   - Read existing messages
   - Write and submit own message
   - Like/unlike other messages

3. **Content Discovery**:
   - Navigate to cubing section for statistics/timer
   - Browse photography gallery
   - Use time travel slider to explore past snapshots
   - Discover Konami code easter egg

## Design Philosophy

1. **Bento-Grid Aesthetic**: Clean, organized layout inspired by Japanese bento boxes
2. **Minimalist Color Palette**: Primarily neutral tones with strategic accent colors
3. **Interactive Feedback**: Clear visual responses to user interactions
4. **Responsive Hierarchy**: Content organized by importance and relationship

## Success Indicators

- Low bounce rate and high engagement time
- Regular guestbook activity
- Positive feedback from visitors
- Technical performance metrics (load time, responsiveness)

## Evolution & Iteration

The website is designed to evolve:

1. **Content Updates**: New photos, projects, and achievements can be added
2. **Feature Enhancements**: Additional interactive components can be integrated
3. **Technical Improvements**: Performance optimizations and code refactoring
4. **Design Refinements**: UI/UX improvements based on user feedback

## Target Audience

1. **Potential Employers**: Looking for technical skills and project experience
2. **University Admissions**: Interested in academic achievements and extracurriculars
3. **Peers & Friends**: Wanting to connect and learn about interests
4. **Technical Community**: Developers interested in implementation details

## Competitive Differentiation

- **Personal Touch**: Reflects individual personality rather than generic templates
- **Technical Depth**: Demonstrates full-stack capabilities with real integrations
- **Interactive Experience**: Goes beyond static content to engage visitors
- **Continuous Evolution**: Shows commitment to improvement and learning
